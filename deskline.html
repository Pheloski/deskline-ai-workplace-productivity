Deskline

An AI-assisted desk for the three drafts that eat a workday: emails, meeting notes, and the daily plan.

note Every draft below is a starting point, not a finished product. Check names, dates, figures and commitments before sending or acting on anything Deskline writes, and use your own judgment on tone and priorities — the model has no visibility into your actual calendar, inbox, or team.

What this is

Deskline is a small prototype built for a productivity-AI project brief. It wraps three workplace tasks — email drafting, meeting-notes summarizing, and daily task planning — around the Claude API, with a separate system prompt engineered for each one.

Prompt engineering approach

Each tool went through at least two rounds. A first-pass prompt ("summarize these notes") produced vague, uneven output that sometimes invented details. The working prompts here fix that by: naming an explicit output structure (fixed section headers, a fixed table format), forbidding invented facts (dates, owners, deadlines not present in the source), and giving tone/audience as explicit parameters rather than folding them into free text. Use "view the prompt" under each tool to see exactly what was sent.

Responsible use

Nothing you type here is stored — each request is sent fresh and nothing is saved between sessions. Outputs can still be wrong, generic, or reflect bias in the underlying model, so they're labeled as drafts throughout, never sent or scheduled automatically, and a review step is left to you before anything leaves this page.
