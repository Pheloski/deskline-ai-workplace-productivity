# Deskline

Deskline is an AI-assisted workplace productivity tool that helps professionals with three common tasks:

- Drafting emails
- Summarizing meeting notes
- Planning daily tasks

## Features

### Smart Email Generator
Creates editable email drafts based on the situation, audience, and tone.

### Meeting Notes Summarizer
Converts raw notes into:

- Key points
- Decisions
- Action items with owners and deadlines

Missing information is marked as `Not specified` instead of being guessed.

### AI Task Planner
Turns a task list into a prioritized schedule with time blocks and productivity suggestions.

## Technology

- Claude API
- Task-specific system prompts
- Self-contained web interface

## Prompt Engineering

Deskline uses structured prompts to improve consistency and reduce fabricated information. Prompts define the required output format and instruct the AI not to invent names, dates, owners, or deadlines.

Users can view the prompts used by each feature.

## Responsible AI

Deskline outputs are drafts and must be reviewed by a human. The tool does not automatically send emails, schedule tasks, or save user input.

Users should verify:

- Names
- Dates
- Figures
- Deadlines
- Commitments

## Impact

Estimated time savings:

- Email drafting: approximately 65–75%
- Meeting summarization: approximately 75–80%
- Task planning: approximately 60–70%

These figures are estimates, not measured benchmarks.

## Future Improvements

- Calendar integration
- Email reply drafting
- Feedback system for improving prompts

## Project Status

Deskline is a prototype demonstrating how focused AI tools can improve workplace productivity while keeping humans in control.
